## 五幕因果链

### 幕 1 — 起点:AI 自主找 alpha(2025-10)
在一家创业公司做技术。最初目标:用 AI 自动寻找 alpha、自动做量化交易。
探索后发现:**纯 AI 自主交易做不成,必须有人介入。**

### 幕 2 — 转向:从"自主交易"到"人在环路的 copilot"
**⚠️ 本幕措辞是当前唯一待确认项。以下是抗打版本(取代"夕阳产业/随机猜测"):**

我们的结论不是"AI 做不了量化",而是关于**瓶颈在哪**:
- 对一个小团队,可持续优势**不在生成策略**——生成很便宜,而且拟合了回测的策略与
  曲线过拟合的噪声无法区分(生成上千个总有碰巧好看的 = 多重检验陷阱);市场非平稳、
  有反身性,边缘一旦被行动就衰减;LLM 本身在严谨数值推理上不可靠。
- 优势**在验证策略**,而验证需要人的判断。
- 所以我们转向:**让人做决策,让 AI 去蒸馏知识、递送信息**。

**为什么这个转向合理(面试要讲的判断力):** 我们在探索自动化的过程中,其实一直在
**蒸馏我们自己和一些专家的领域知识**。既然真正在积累的是"知识 + 信息优势",那更
自然的产品形态是:把这些知识 + 我们的新闻信息 + 回测系统**打包教给用户**,而不是
藏在一个不可信的自主交易黑箱里。

> 抗打口径速记:不是"量化在死",是"**小团队能拿到的系统性 alpha 在衰减**"
> (alpha decay / 因子拥挤 / 数据与延迟护城河被巨头占据)——这句真实且攻不破。

### 幕 3 — 我的领地:用户记忆 + 信息消化(2026 上半年)
我负责的产品模块:
- **每个用户的记忆怎么存**、如何让用户的个人 agent 拥有**长期记忆**;
- 我们推给 agent 的信息(**新闻、回测**)该**怎么消化处理**,才能让 agent 与用户的
  交互流畅。

> **白捡的呼应**:这个"记忆系统"正是 postTrain **v0.4 考卷考的东西**——孪生对
> 设计(同一问题、记忆内容不同则正确答案翻转),逼策略真的用上记忆而不是忽略它。
> 产品侧的我和训练侧的我,是同一个问题的两端。深挖时甩出来。

### 幕 4 — 问题浮现:决策不稳定 → 三重保障
做这个产品时,发现 **agent 的决策不稳定**——会幻觉、乱说、乱决定,让我们恐慌。
在一个**涉及钱的金融产品**里,"乱决定"是要赔钱的,我们要给用户**最大的安全感**。
prompt 试过,但**无法保证输出绝对稳定**。所以衍生出**三重保障**:

**代码层 guardrails(硬红线) + prompt + 后训练模型。**

四个具体事故(把"决策不稳定"填实,面试必被追问"举例"):

| 事故(口语) | 具体表现 | 量化后续 | → 任务 |
|---|---|---|---|
| 幻觉乱说 | 给结论时引用**不存在的来源 ID** | 长 ID 场景 prompted 伪造率 **0.871** | citation |
| 乱决定(最恐慌) | 用户"2x 杠杆 SOXL 当对冲",agent 顺着聊而不熔断交人 | AMD_00 仲裁案题材 | risk gate |
| 乱烧钱 | 同一查询,时而秒答时而拉起完整研究链,成本差一个量级 | escalation 环境 | escalation |
| 轰炸用户 | 同结论新闻刷屏式推送 | MU×3 洪流 → 1 张干净卡 | digest |

安全为什么必须留在**代码层**而不赌 RL 学会:我们自己的仪器化 RL 实验证明,纯 RL 会
**漏掉恰恰是这种罕见、硬的约束**(0.5B collapse 的零梯度机制)——所以熔断是
versioned code floor。

### 幕 5 — 副产品:决策点可观测 + 轨迹打点
探索后训练时,额外收获:**能更清楚看到系统的决策点在哪出错**。
同时我们对用户决策**打点收集轨迹**(DecisionSnapshot 点时冻结)。

> **⚠️ 已实现用途 = 决策质量复盘 / 防事后美化。** 见 DECISION_NODE_RECORDING_SPEC。

## v0.4 首考实证(EXP-2026-07-08-001)——幕 3 呼应的数字化

1.5B **prompted 基线**,冻结 test n=121 / 48 twin / 6 gate seed,三臂 none/digest/raw:

| arm | reward@0.3 | success | twin 判别率 | prompt tokens |
|---|---|---|---|---|
| none | 0.7052 | 0.984 | 0/48 (0%) | 305 |
| digest | 0.7022 | 0.950 | 2/48 (4.2%) | 456 |
| raw | 0.4770 | 0.645 | 5/48 (10.4%) | 1078 |

**两条 headline:**
1. **记忆需要训练。** digest 对 none 几乎零增益(reward 0.7022 vs 0.7052,twin 判别仅
   0→4.2%)——prompted 阶段**用不上手里的记忆**。这不是终局,是**训练的动机**:
   记忆利用这个行为不是 prompt 白给的,得训进去。**训练臂是下一步(pending)。**
2. **长上下文淹没小模型。** raw 记忆(1078 token)信号最多(twin 判别 10.4% 最高,
   说明模型确实更多地读了它),但 success **崩 -34pts**(0.984→0.645)——读得多、
   却决策更差。**压缩论点被机制性证实。**

**产品呼应(白捡):** KIWI 的 **digest 引擎给摘要而非原文 dump**——训练侧独立证明了
原文 dump 会淹死小模型,digest(456 token)几乎不掉 success。产品设计和训练发现互为佐证。

> 诚实边界:prompted 单基线、n=121、twin 绝对数小(0/2/5)——方向清楚,别把
> 4.2% vs 10.4% 当成强结论,真正硬的是 success 的 -34pts 崩塌 + digest 零增益。

## 面试安全口径 & "别说"清单

**R1 — 数据用途(红线)。** 轨迹打点的**已实现用途是决策质量研究与产品改进**
(retrospective + DecisionSnapshot 冻结)。**绝不主动提**"收集用户决策以反向大众做交易"——
这在任何公司面试官耳里都是"平台用用户数据与用户对赌"的伦理红旗(front-running 既视感),
Anthropic 尤其致命。若被直接追问轨迹用途:决策质量复盘。反向信号**是内部研究假设、从未
实施**(事实如此)。committed 文档一个字不写反向交易。

**R2 — 纯 AI 失败原因。** 用幕 2 的抗打版本(验证瓶颈 + alpha 衰减),**不要**说
"夕阳产业""随机猜测"。这两个词会被当场击穿。

**R3 — 商业现状。** "1000+ 注册、80–90 活跃(含我们自己)"——如实,**不提收入/不吹留存**;
被问激活率就承认早期。这是真实产品的证据,已经够用。

**R4 — 一致性。** "我 / 我们(团队)/ 公司"要分清:记忆系统、信息消化 = **我(I)** own;
转型、产品定位 = 公司/团队(we)。时间线与简历经历条目严格对齐,经得起背调。

## 面试就绪的压缩版本

**30 秒前传(接在 pitch 之前或深挖时用):**
> 我在一家创业公司做技术。我们一开始想用 AI 自主找 alpha 做量化,但很快发现瓶颈不在
> 生成策略——那很便宜也容易过拟合——而在验证策略,而验证需要人。所以转向了人在环路的
> 理财 copilot:让 AI 蒸馏知识、递送新闻和回测,让人做决策。我负责用户的长期记忆和信息
> 消化。做的过程中发现 agent 决策会幻觉、会在涉及钱的地方乱决定,prompt 保证不了绝对稳定——
> 这就是我去做"代码红线 + prompt + 后训练"三重保障的起点,也是 postTrain 这个训练项目的出生证明。

**一句话因果链(被问"这俩项目什么关系"):**
> KIWI(产品)负责发现失败,postTrain(训练)负责把失败转成可测可训的任务再回答它;
> 我在产品侧负责的记忆系统,正是训练侧 v0.4 考卷考的能力。
